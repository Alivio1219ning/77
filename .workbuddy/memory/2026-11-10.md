## 2.5D 自由移动、AABB 碰撞、动态 Z 遮挡与立体跳跃

- **坐标重构**：`S.charX`（水平 %）+ `S.charY`（脚底纵深 %，从舞台顶部量起，越小越靠里）。
  `DEPTH_HOME_Y=89`（对应 `CHAR_GROUND_RATIO 11%` 的地面线）、`DEPTH_SPEED=13`（< `MOVE_SPEED 19`，透视减速）。
  `syncDepthVisual()` 用 `translateY(-(89-y)/100*stageH())` 把纵深映射到屏幕，同时把 `z-index` 写成 `depthZ(y)`；
  小喵与尾巴同步位移。`renderPhysics()` 每帧调用它，保证 z 永远跟着脚底 y。
- **深度 z 带**：`depthZ(y)=30+round((y-60)*0.5)`，角色与实体共用 30..48。
  实体 z 固定（= `depthZ(box[3])`），角色 z 动态 → y 小于实体 y 时被挡，大于时挡住实体。
  CSS 末尾一条覆盖规则把 `.gs-fg/.gs-mate/.gs-collect/.gs-dialog/.gs-panel/.room-quilt/.room-dim-veil` 等
  常驻 UI 统一抬到 `z-index:70`，避免穿过深度带。`run_door.js` 旧断言写死 `.gs-door-fx z=31`，
  按新设计改为「>=49（高于深度带上沿）」。
- **可行走区域 `WALK_AREAS`**（8 个场景，均带 note）：`minX/maxX/minY/maxY` 卡死花墙/天空与海面/前排地板；
  `rects`（小屋地毯+木地板两块矩形）、`poly`（海边梯形栈道+沙滩，射线法 `pointInPoly`）、
  其余纯矩形边界。`depthSanitize()` 在每次位移前把越界坐标就近吸附回可走区，避免旧存档/测试直赋值卡死。
- **实体 `SOLID_PROPS`**：8 场景各 3-5 件，`box` 同时作为 AABB 命中盒与绘制矩形，
  `top` 为可站立面、`surface` 为台面高度(px)、`door+act` 为切换点。
  `depthPropArt(type)` 用内联 SVG 画床/长椅/桌/吧台/书架/树/秋千/门/邮筒/木箱，
  `renderDepthProps()` 把它们作为 `#game-stage` 的**直接子节点**插入（与 `#character` 同层才能比 z-index），
  `pointer-events:none` 保证不挡热点点击。
- **`updatePosition(dx,dy,dt)`**（新主循环核心）：四向输入 `keys.a/d/w/s` → `moveFrame` 每帧算 `dir/dy` 调用；
  `charBox()` + `aabbOverlap()` 做 AABB；先试双轴，被挡则逐轴回退实现贴墙滑动；
  木门命中不穿模、只按 1500ms 节流触发 `roomDoor/goHome/doorDream/leaveCarriage`
