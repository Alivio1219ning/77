# 2026-11-09

## 核心手感升级：全局按键状态 + rAF 主循环 + 三段式跳跃重力引擎（14:50–15:35）

### 根因
旧 `moveFrame` 在 `dir===0`（A+D 同时按住）时直接 `endMove(); return;` **销毁 rAF**；
`releaseHold('L')` 只清标志不重启循环 → 松开 A 后 D 仍按着却不动，必须全松再按。
旧空格直接 `tryNearby('space')`，无跳跃。

### 移动重写
- 新增唯一真相源 `const keys = {a:false,d:false,space:false}`，`MOVE_KEYS` 值改 'a'/'d'；
  `heldDir` 降为兼容镜像（`setKey` 同步）。
- `setKey(name,down)` 只置位 + `startMainLoop()`；keydown/keyup 不再直接位移。
- `moveFrame(t)` 常驻主循环：每帧 `dir=(keys.d?1:0)-(keys.a?1:0)`，两键抵消时**不 return 不销毁**；
  有方向键 / 人在空中才继续排队 rAF，空闲休眠（`moveLastT=0`），按键或切场景由
  `startMainLoop()` 唤醒（避免 jsdom 测试进程被常驻 rAF 挂住）。
- 保留兼容接口 `MOVE_SPEED / heldDir / stepMove / moveChar / startHold / releaseHold / endMove / bindMove`，
  15 套旧回归零改动通过。
- 键盘加 `isTyping()` 保护（input/textarea/contenteditable 不劫持）。

### 跳跃物理
- `phys={y,vy,gravity,isGrounded,jumpCount,floating,feather}`；`GRAVITY=.8 / JUMP_VY=-15 /
  DOUBLE_VY=-12 / FLOAT_HOLD=200 / FLOAT_CEIL=118 / FEATHER_MAX=4.6 / PHYS_STEP=1/60`。
- 固定 60Hz 步长积分（`physAcc` 累加，每帧最多 6 步），单步公式严格 `vy += gravity; y -= vy`
  （y = 离地高度，`y<=0` 即落地）；跨刷新率手感一致。
- 单跳 jumpCount=1 + `jump-launch` 拉长；二段跳 vy=-12、jumpCount=2 + `jumpPuff()` 11 块白色像素云；
  第三次按空格不生效。落地 `land-squash` 压扁 + 7 块小云 + 全状态复位。
- 长按空格 >200ms 且在空中 → `floating=true`：gravity 减半 0.4、升力把 vy 拉向 -1.9 缓升、
  到 118 悬停、`.gs-float-stars` 5 颗金色 ✦ 环绕；松开 → `feather=true`，重力回 0.8 +
  `vy*=.93` 且终端速度 4.6 的羽毛缓降。

  + `.gs-char-lift`（只抬小人，内含原 `.gs-char-ground > .gs-char-float > .gs-char-pose > #gameAvatar`
  与 5 颗星；`rug-thought`/`gs-zzz` 仍在 lift 外）。`run_micro` 的后代选择器断言不受影响。
- `renderPhysics()` 每帧写 lift 的 `translateY(-y)`、`--sh-op`/`--sh-scale`（高度越高阴影越小越淡）、
  `airborne` / `air-move` class、`--air-tilt`（向左 -7deg / 向右 7deg 前倾）。
- 起跳拉长、落地压扁动画放在 `.gs-char-float`，**不碰 `.px-avatar`**，避免吃掉
  `.face-left{scaleX(-1)}` 翻转。删掉最初加的 `.airborne .px-avatar{drop-shadow}`——它会让角色
  「自带一团影子跟着飞」，破坏地面阴影的空间感。
